womm

A courtroom for "works on my machine" bugs.

It works on your teammate's laptop and not on yours. womm compares the two machines, checks what your project says it needs, and puts the likely causes on trial.

$ womm trial --against works.womm.json

THE PEOPLE v. YOUR MACHINE

GUILTY     node 16.20.0
           .nvmrc requires node 22.11.0
           Fix: Install a node version matching 22.11.0.

SUSPICIOUS Python 3.12 removed distutils
           Code or packages importing distutils fail on Python 3.12.
           Fix: Install setuptools, or update the package that imports distutils.

ACQUITTED  Git 2.47.0
           Theirs: 2.52.0

1 guilty, 1 suspicious, 1 acquitted. The court recommends dealing with the guilty parties first.

How it works

  1. Run womm snapshot -o works.womm.json on the machine where it works.
  2. Review the file and share it.
  3. Run womm trial --against works.womm.json on the machine where it fails.

Verdicts are informed guesses with the evidence shown, not proof. Snapshots leave out hostnames, secrets and your name.

See all known causes, or add your own. Each is one small file.

Also included: a joke certificate for machines that meet a project's stated requirements, and a badge for your README.
