# Security policy

Please report these privately instead of opening a public issue, using GitHub's private vulnerability reporting for this repository:

- A snapshot recording private data, such as a name, secret or full path
- A way for a snapshot or rule file to run code or harm the machine reading it
- A way for hostile text to escape from a report or certificate
- A way for files in a repository to run code when `womm` is used inside it

Snapshots and rule files are treated as untrusted input, so these count as real bugs.

Only the latest release receives fixes.
